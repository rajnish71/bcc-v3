# PURPOSE

This document defines the constitutional rules governing the one-time migration of historical Bhopal Camera Club members into the BCC Unified Platform V3.

The objective of this migration was to preserve historical continuity while transitioning to the new Membership Architecture without compromising constitutional integrity.

This migration is complete.

This document is now frozen.

---

# CONSTITUTIONAL PRINCIPLES

The legacy migration shall preserve:

- Historical membership identity
- Historical continuity
- Permanent membership numbers
- Legacy recognition
- Repository integrity

The migration shall never compromise:

- MEM-006
- MEM-007
- MEM-008
- Identity Architecture

# MIGRATION SCOPE

The migration covered:

- Historical users

- Public photographer profiles
- Membership history
- Permanent membership number allocation

# PERMANENT MEMBERSHIP NUMBERS

Membership numbers assigned during LEGACY-001 are permanent.

They shall never be:

- renumbered
- reused
- reassigned
- regenerated
- manually modified

MEM-007 governs all future numbering.

# MIGRATION IMMUTABILITY

Migration history is immutable.

The following are permanently prohibited:

- Re-running legacy migrations
- Reallocating permanent numbers
- Reclassifying migrated members through migration
- Editing migration history
- Renumbering historical members

Historical corrections, where genuinely required, must be performed through explicit administrative data reconciliation and must never modify the historical migration itself.
